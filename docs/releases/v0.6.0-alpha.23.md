# DeepSee 0.6.0-alpha.23

DeepSee's model directory is now substantially shorter and calmer without hiding any provider or model.

## Highlights

- Render the four column labels once for the complete directory instead of once per provider.
- Merge provider cards into one continuous native-style list with subtle separators.
- Reduce provider header and model row heights while preserving switches, model selectors, source, and editable capabilities.
- Replace repeated enabled-state copy with a compact model count; the full count remains available on hover.
- Keep the model directory and every provider visible—no forced folding or hidden Runtime state.

## Verification

- UI contract, syntax, type, package, and installed-browser verification completed.
