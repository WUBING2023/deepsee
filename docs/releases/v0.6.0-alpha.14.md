# DeepSee 0.6.0-alpha.14

DeepSee 0.6.0-alpha.14 makes native Harness Workflow routing reliable across Standard, Code, Prime, Web, and Headless modes, and turns detected local Codex into a real selectable executor instead of a shell fallback.

## Highlights

- Routes native Workflow children through DeepSee's registered subagent provider before choosing the underlying runtime.
- Uses Harness's official preset-service addressing API, so isolated Standard and Code Workflow engines work without editing shipped preset files.
- Sends `cli:codex` and `cli:claude-code` routes to their native Harness providers; ordinary Harness and API routes continue through the built-in spawn provider.
- Removes the unsafe PowerShell fallback path for failed CLI children, preventing unnecessary full-access approval prompts.
- Adds regression coverage for preset isolation, explicit provider overrides, native CLI routing, and plugin-bundle configuration.
- Expands the built-in model-capability catalog and initialization guidance while keeping user-edited model descriptions authoritative.

## Verified behavior

The release candidate was exercised through the official Harness Headless Standard preset with one native Workflow child assigned to `cli:codex`. Codex returned `DEEPSEE_CODEX_OK`; Harness recorded one completed Workflow agent, no shell fallback ran, and no workspace file was changed.

## Install or upgrade

```powershell
npx --yes github:WUBING2023/deepsee install
```

Then refresh or restart DeepSeek Harness Web. Requires Node.js 24 or newer and is tested against DeepSeek Harness `0.1.0-rc.6`.

# DeepSee 0.6.0-alpha.14 中文说明

DeepSee 0.6.0-alpha.14 修复了 Standard、Code、Prime、Web 与 Headless 模式下的原生 Workflow 路由；本机已识别的 Codex 现在会作为真正的子代理 Runtime 执行，而不是失败后退回 PowerShell。

## 主要改进

- 原生 Workflow 创建子代理前，先经过 DeepSee 注册的模型路由供应商。
- 使用 Harness 官方的预设服务寻址接口，兼容隔离的 Standard 与 Code Workflow 引擎，无需修改官方预设文件。
- `cli:codex` 与 `cli:claude-code` 交给 Harness 原生供应商；普通 Harness/API 模型继续复用内置 spawn 路线。
- 禁止 CLI 子代理失败后通过 PowerShell 兜底，避免无意义的“完整权限”审批。
- 增加预设隔离、显式供应商覆盖、CLI 原生路由和插件配置契约的回归测试。
- 扩充默认模型能力目录与初始化说明，同时继续以用户修改后的模型描述为准。

## 真实验证

候选版本已通过官方 Harness Headless 的 Standard 预设实测：原生 Workflow 只启动一个 `cli:codex` 子代理，Codex 返回 `DEEPSEE_CODEX_OK`；Harness 记录该子代理成功完成，未调用 PowerShell，也未修改工作区文件。

## 安装或升级

```powershell
npx --yes github:WUBING2023/deepsee install
```

安装后刷新或重启 DeepSeek Harness Web。需要 Node.js 24 或更高版本，当前针对 DeepSeek Harness `0.1.0-rc.6` 完成验证。
