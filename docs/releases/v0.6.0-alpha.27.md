# DeepSee 0.6.0-alpha.27

This release turns DeepSee into an atomic, reusable plugin group and closes the pre-alpha plaintext credential path.

## Highlights

- Publish one installable group with reusable core, Codex adapter, Web client, and Workflow-policy exports.
- Remove the legacy API-key setup/test commands and make the old raw-key model endpoint fail closed in favor of Harness **Settings → Models**.
- Detect inactive pre-alpha plaintext credentials without reading them into a provider; remove them only through the explicit `doctor --scrub-legacy-secrets` action.
- Remove stale generated API routes when that explicit migration runs, without touching unrelated environment settings.
- Apply Focused, Balanced, or Deep Workflow reasoning guidance without a hard runtime, token, step, or agent cutoff.
- Remove every registered group alias and the DeepSee-owned Prime preset through one uninstall command while preserving user state and managed OCR.
- Add clean-runner installation smoke coverage for Windows, macOS, and Linux, including folder staging, security migration, OCR catalog, and Runtime catalog checks.

## Upgrade note

Provider credentials now belong exclusively to DeepSeek Harness. If an early alpha stored a key in DeepSee's `.env` or `.opends-connections.json`, first reconfigure that provider in Harness, then run:

```powershell
deepsee doctor --scrub-legacy-secrets
```

Keys previously pasted into a chat or committed elsewhere must still be revoked and replaced at the provider.
