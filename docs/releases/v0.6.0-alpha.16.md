# DeepSee 0.6.0-alpha.16

DeepSee now opens as a native DeepSeek Harness settings page from its permanent sidebar entry.

## Highlights

- Keep the compact `见 / 深见` action in the Harness sidebar.
- Open the registered `深见` settings section through the Harness settings shell.
- Remove the duplicate DeepSee-owned overlay, header, mask, and close controls.
- Preserve the existing model matrix, base-model selector, visual reader, OCR management, and Workflow preferences.
- Keep `+ 添加模型` connected to the Harness native model page.
