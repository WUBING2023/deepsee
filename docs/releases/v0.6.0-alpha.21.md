# DeepSee 0.6.0-alpha.21

DeepSee now lets one verified subscription or desktop-backed Runtime expose several independently managed models at the same time.

## Highlights

- Start every detected CLI subscription with one model, keeping first-run setup compact.
- Add more verified models under the same Claude Code or Codex source without replacing the current one.
- Change, enable, disable, and remove added model instances directly in the four-column model directory.
- Give every model instance a stable route so it can independently become the base model or a Workflow child.
- Keep sibling subscription models inside one Harness provider group instead of duplicating the source.
- Prevent duplicate model instances and preserve managed models across startup Runtime verification.
