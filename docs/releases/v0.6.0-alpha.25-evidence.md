# DeepSee 0.6.0-alpha.25 Verification Evidence

Verified on Windows with DeepSeek Harness `0.1.0-rc.6`, with the release workflow repeated on GitHub's Linux runner.

## Runtime and vision contract

- Claude Code and Codex adapters preserve original Harness image attachments.
- Codex uses App Server `UserInput.image` data URLs.
- Claude Code uses native stream-json image content blocks.
- Runtime discovery records executable startup, authentication, adapter support, input modalities, and model-specific vision separately.
- Claude vision probes are cached for 24 hours and can be forced from the `验证` action.
- Gemini must complete a minimal headless request before its switch is enabled.

## Real environment results

- Codex `gpt-5.6-sol`: `DEEPSEE_CODEX_VISION_OK`; correctly identified the DeepSee model-routing dashboard.
- Claude `sonnet`, `opus`, and `fable`: returned `[Unsupported Image]`; retained as text/code Runtimes and excluded from the visual selector.
- Gemini CLI: installed but signed out; shown disabled with a login explanation.
- Kimi CLI: installed but lacks a Harness adapter; shown disabled.
- DeepSeek V4 Pro placeholder profile was migrated to concrete capabilities.
