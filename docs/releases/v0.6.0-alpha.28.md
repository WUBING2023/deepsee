# DeepSee 0.6.0-alpha.28

This release adds a bilingual, evidence-based product demo and makes the public release page explain DeepSee by showing the real route end to end.

## Highlights

- Add separate 38.5-second Chinese and English product films rendered from one deterministic timeline.
- Show the real DeepSee experience: one-line installation, visual-model or local-OCR selection, verified model routing, visible multi-agent Workflow execution, and directly openable deliverables.
- Publish a full sound mix and a no-background-music variant for each language.
- Embed the localized demo in the English and Chinese product pages, with downloadable alternate versions.
- Add explicit public privacy and independence boundaries: provider keys remain owned by Harness, selected providers receive only the content routed to them, and local OCR remains local.
- Ship the reproducible Remotion source, real public interface captures, design specification, audio attribution, and independent final-review evidence.
- Make managed OCR bootstrap resilient on older Windows: Node HTTPS, curl, PowerShell TLS 1.2, and Python download paths are tried independently, while the UV archive remains fail-closed against the official GitHub Release SHA-256 digest.
- Detect the known Windows `WinError 1114` / `c10.dll` PyTorch startup failure during MinerU setup, retry with the official PyTorch 2.8 CPU compatibility pair, and surface an actionable Microsoft Visual C++ runtime link when the operating-system dependency is still missing.
- Force UTF-8 for managed Python processes so Windows installation diagnostics remain readable instead of displaying mojibake.

## Upgrade note

There is no configuration migration in this release. Existing DeepSee installations can upgrade normally; the product demo and release-page improvements do not change stored routes, credentials, or OCR installations.
