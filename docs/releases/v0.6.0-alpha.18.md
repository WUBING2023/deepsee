# DeepSee 0.6.0-alpha.18

DeepSee now truly inherits global Claude and Codex user memory instead of only displaying detected instruction files.

## Highlights

- Read conventional global `AGENTS.md`, `CLAUDE.md`, and `agent.md` files from the user directory, Claude config, and Codex config without modifying them.
- Inject inherited memory into ordinary Harness base sessions and preserve the assembled system prompt when Codex or Claude Code is selected as the base runtime.
- Pass the same memory to direct CLI model calls and native Workflow children.
- Keep Harness-native `$DSH_HOME/AGENTS.md` out of the import path to avoid duplicate instructions.
- Deduplicate identical files, enforce per-file and total size limits, and expose only safe metadata to the sidebar.
- Keep the current explicit user request authoritative over conflicting persistent preferences.

## Verification

- TypeScript typecheck passed.
- 30 test files / 135 tests passed.
- Local global-memory discovery found the configured Claude source without exposing its contents in public state.
- A real DeepSeek base session, a direct `opends_run_model` Codex call, and a visible native Workflow Codex child all returned the expected marker from a temporary non-sensitive global memory source.
