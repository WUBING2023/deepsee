# DeepSee 0.6.0-alpha.13

DeepSee's first traceable public Alpha release packages the current DeepSeek Harness plugin, its one-command installer, and the release infrastructure needed to verify every published file.

## Highlights

- Automatically selects the first ready visual model, or lets the user manage MinerU, PaddleOCR, and RapidOCR as complementary local OCR readers.
- Detects Codex and Claude desktop apps as well as CLIs. Codex can reuse its bundled App Server; Claude requires a verified Claude Code CLI for automatic execution.
- Shows a simple stage progress bar and a compact fit comparison while a local OCR runtime and models install.
- Keeps each OCR in an isolated environment and safely uninstalls only DeepSee-managed files.
- Reuses Harness-native providers and credential references without copying raw API keys.
- Reuses existing `AGENTS.md` and `CLAUDE.md` instructions, with additional lowercase `agent.md` compatibility.
- Installs into Web and Headless profiles and supports resumable updates and ZIP fallback recovery.
- Publishes an exact package, SHA-256 checksum, bilingual product page, and auditable release contract.

## Install

```powershell
npx --yes github:WUBING2023/deepsee install
npx --yes github:WUBING2023/deepsee web
```

Requires Node.js 24 or newer. This Alpha is tested against DeepSeek Harness `0.1.0-rc.6`.

## Current limits

- Kimi CLI, OpenCode, and Ollama are discovery-only until stable Harness execution adapters are available.
- Local OCR installation still needs a compatible Python/UV route and network access for dependencies and model files. PaddleOCR on Windows requires an ASCII model-cache path; DeepSee chooses one automatically unless the path is overridden.
- DeepSee is Alpha software; Harness preview releases may require compatibility updates.

## Integrity

Download `deepsee-0.6.0-alpha.13.tgz` and the adjacent `.sha256` file from this Release. The checksum is generated from the same tagged CI build that runs type checking, all tests, package smoke tests, and product-site validation.

# DeepSee 0.6.0-alpha.13 中文说明

这是 DeepSee 第一个具备完整追溯链的公开 Alpha：当前 DeepSeek Harness 插件、一行安装器、精确发布包、SHA-256、中英双语官网与发布契约会来自同一个受审查版本。

## 主要内容

- 自动选择 Harness 中首个可用视觉模型，也可管理互补的 MinerU、PaddleOCR、RapidOCR 本地读取器。
- 同时发现 Codex、Claude 桌面端与 CLI；Codex 可复用内置 App Server，Claude 自动执行仍需通过验证的 Claude Code CLI。
- 安装本地 OCR Runtime 与模型时显示简单阶段进度条和紧凑的适用场景对比。
- 每个 OCR 使用隔离环境，只卸载 DeepSee 管理的文件，不影响系统安装。
- 复用 Harness 原生供应商与凭据引用，不复制原始 API Key。
- 沿用已有 `AGENTS.md`、`CLAUDE.md` 指令，并额外兼容小写 `agent.md`。
- 同时支持 Web 与 Headless，安装和升级可续跑，并提供 ZIP 兜底。

## 当前限制

- Kimi CLI、OpenCode 与 Ollama 在稳定适配器完成前仅用于发现。
- 本地 OCR 仍需要兼容的 Python/UV 路线，并联网下载依赖与模型文件。Windows 上 PaddleOCR 需要纯英文模型缓存路径；未手动覆盖时 DeepSee 会自动选择。
- 当前仍是 Alpha；Harness 预览版演进时可能需要兼容更新。
