# DeepSee 0.6.0-alpha.29

This compatibility release makes the older-Windows OCR recovery work available through DeepSee's normal update path.

## Highlights

- Detect the known Windows `WinError 1114` / `c10.dll` PyTorch startup failure during managed MinerU installation.
- Retry the affected environment with the official PyTorch 2.8 CPU compatibility pair before MinerU verification.
- Provide the official Microsoft Visual C++ 2015–2022 x64 Redistributable recovery link when the operating-system runtime is still missing.
- Force UTF-8 for managed Python processes so Windows OCR installation diagnostics remain readable.
- Retain the resilient UV bootstrap introduced in alpha.28: Node HTTPS, curl, PowerShell TLS 1.2, and Python download paths remain independent, and the portable UV archive remains fail-closed against its official SHA-256 digest.

## Upgrade note

There is no configuration migration. DeepSee preserves Harness credential references, model preferences, Workflow policy, and managed OCR state. After upgrading, restart DeepSeek Harness before retrying a failed MinerU installation.
