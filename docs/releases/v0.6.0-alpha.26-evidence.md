## Regression boundary

- Nested images returned by tools are replaced inside the original `tool-result`, retaining its exact `toolCallId`.
- A missing selected OCR executable cannot leave the bridge in a false OCR-ready state; another ready OCR is selected, otherwise a verified visual model is used.
- Subscription base-model requests without an explicit session id use the live Harness initiator.
- No API key or subscription token is included in diagnostics, release files, or evidence.
