# DeepSee 0.6.0-alpha.15

DeepSee now exposes verified Codex and Claude Code subscription runtimes as real DeepSeek Harness base-model providers, not only as implicit Workflow children.

## Highlights

- Select authenticated Codex models (`gpt-5.6-sol`, `gpt-5.6-terra`, and other locally advertised models) directly from the Harness model selector.
- Select authenticated Claude Code models (`sonnet`, `opus`, `haiku`, and other locally advertised models) directly from the Harness model selector.
- Use `opends_run_model` for one explicit model delegation without forcing a multi-agent Workflow.
- Keep native Harness Workflow routing for `cli:codex` and `cli:claude-code`; each route uses the subscription model selected in the DeepSee panel.
- Allow a verified CLI subscription route to be saved as the DeepSee primary/base model.
- Fail loudly when a requested CLI model is not in the runtime's verified catalog.
