# DeepSee 0.6.0-alpha.30

This installer reliability release replaces the ambiguous GitHub `npx` entry with an explicit, versioned Release-package command.

## Highlights

- Publish a dependency-free DeepSee bootstrap package so npm can start the CLI without resolving the complete DeepSeek Harness peer graph first.
- Invoke the scoped `@deepseek-ai/dsh` package through its explicit `dsh` executable, fixing the Windows command-resolution failure.
- Vendor the small MIT-licensed JSON-RPC line transport used by the Codex adapter, removing the bootstrap package's only runtime dependency.
- Make the website, README, getting-started guide, troubleshooting guide, and installer completion message use `npm exec --package=... -- deepsee`.
- Preserve all alpha.29 MinerU compatibility repairs, including the Windows PyTorch CPU fallback and UTF-8 diagnostics.

## Install

```powershell
npm exec --yes --package=https://github.com/WUBING2023/deepsee/releases/download/v0.6.0-alpha.30/deepsee-0.6.0-alpha.30.tgz -- deepsee install
```

The command prints the target `DSH_HOME`, Web/Headless profiles, and installation progress as soon as DeepSee starts. Existing Harness credentials and DeepSee preferences are preserved.
