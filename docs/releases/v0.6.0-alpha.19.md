# DeepSee 0.6.0-alpha.19

DeepSee corrects the model-directory hierarchy so the directory itself is always visible and individual sources own their model lists.

## Highlights

- Keep `模型目录` permanently visible instead of hiding the whole catalog inside one disclosure.
- Group routes under API providers, Harness providers, local CLIs, and desktop-backed runtimes.
- Give every source group its own four-column list: enabled, model, source, and capability.
- Keep verified subscription-model selectors inside the corresponding Codex or Claude runtime group.
- Show source-level enabled and selectable-model counts without exposing route IDs.
