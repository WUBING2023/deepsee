# DeepSee 0.6.0-alpha.22

DeepSee can now add a missing CLI Runtime directly from the model directory instead of requiring a separate terminal setup.

## Highlights

- Add a compact `+` action beside the model-directory count.
- Select Gemini CLI and an isolated install path without leaving DeepSeek Harness.
- Install the official stable npm package in the background with visible progress.
- Fall back to Google's official GitHub Release bundle when npm is unavailable or fails.
- Verify the resulting executable and add Gemini CLI to Runtime discovery automatically.
- Expose Gemini Auto, Pro, Flash, and Flash-Lite as independently manageable base-model and Workflow routes after restart.
- Preserve user files by rejecting filesystem roots and unrelated non-empty folders.
- Force-refresh local development installs so same-version rebuilds cannot leave stale plugin files in Harness.

## Verification

- TypeScript validation passed.
- The managed installer completed an end-to-end isolated npm-prefix simulation and executable probe.
- Full automated verification passed before packaging.
