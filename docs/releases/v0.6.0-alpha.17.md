# DeepSee 0.6.0-alpha.17

DeepSee keeps the model page compact and exposes one selected model per subscription account by default.

## Highlights

- Collapse the full model directory by default behind a compact route summary.
- Keep the four-column matrix available on demand without occupying the entire settings page.
- Select the first verified Codex or Claude Code model automatically for a new subscription Runtime.
- Expose only that selected subscription model to the Harness base-model catalog.
- Continue showing the full verified model list inside the subscription row selector, so switching models remains one action plus a Harness restart.
- Exclude DeepSee-generated CLI adapter groups from registry synchronization to avoid duplicate model rows.
